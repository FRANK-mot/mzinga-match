# 🍍 Mzinga Match

**Find someone nearby who's ready to share a mzinga.**

A fun Tinder-style app inspired by the viral post:

> Why is there still no app for finding someone to drink with?  
> Imagine just swiping and seeing “Vanessa, 300 metres away, has a mzinga of KC Pineapple.”  
> Now that’s a match.

## Live Demo

👉 **[Open Mzinga Match](https://frank-mot.github.io/mzinga-match/)**

(Works best on mobile — you can even “Add to Home Screen” and it feels like a real app)

## Features

- Swipe cards left/right (or use the buttons)
- See distance + what drink they have
- Match animation
- Matches list
- Dark, modern UI with pineapple vibes
- Progressive Web App (installable)

## How to run locally

Just open `index.html` in a browser, or:

```bash
npx serve .
```

## Built with

- Vanilla HTML, CSS, JavaScript
- Tailwind CSS
- Pure love for KC Pineapple 🍍
